# 🎨 SlideTuningStudio (슬라이드 튜닝 스튜디오)

> **교실과 강연을 위한 올인원 AI 슬라이드 & 발표 대본 저작 스튜디오**  
> 설치도, 복잡한 빌드도 필요 없는 **단일 HTML 기반 웹 애플리케이션**입니다.  
> 5대 전문 브랜드 테마, TeXZilla 오프라인 수식 렌더링, Gemini 기반 양방향 AI(대본 ⇄ 슬라이드), 학생 화면 연동 발표 모드, A4 1:1 무왜곡 인쇄를 모두 지원합니다.

---

## 🌟 프로젝트 개요

**SlideTuningStudio**는 수업과 교원 연수, 공개 발표를 준비하는 교사와 발표자를 위해 기획된 지능형 슬라이드 저작 도구입니다.

기존 프레젠테이션 소프트웨어의 한계(슬라이드와 대본의 분리, 복잡한 서식 조절, 외부망 차단 환경에서의 수식 깨짐 등)를 해결하고, **슬라이드와 발표 대본을 한 화면에서 유기적으로 조율**할 수 있도록 설계되었습니다.

- **⚡ Zero Setup**: 서버나 프레임워크 없이 웹 브라우저에서 즉시 실행 (Vercel 정적 배포 지원)
- **🧠 양방향 AI 엔진**: 슬라이드로 맥락 맞춤 대본 작성 ⇄ 대본으로 테마 슬라이드 자동 기획
- **📐 오프라인 수식 완벽 지원**: TeXZilla 엔진 내장으로 인터넷 없이도 LaTeX/MathML 수식 렌더링
- **🖥️ 독립 발표자 모드**: 학생용 프로젝터 창(`?mode=screen`)과 발표자 창 실시간 무선 동기화
- **🖨️ A4 1:1 완벽 분할 인쇄**: 벡터 스케일러(Print Scaler) 적용으로 캔버스와 100% 동일한 비율 출력

## 🚀 주요 기능 (Key Features)

### 1. 🎨 5대 전문 브랜드 적응형 테마 (Adaptive Theming)
슬라이드의 목적과 발표 분위기에 맞추어 5가지 전문 디자인 테마를 실시간으로 전환할 수 있습니다. 테마 변경 시 카드 배경색, 테두리, 모서리 각도, 글자색이 자동으로 재계산되어 일괄 조율됩니다.

| 테마 | 스타일 특징 | 모서리 곡률 | 추천 상황 |
| :--- | :--- | :---: | :--- |
| **모던 에듀 블루** | 신뢰감 있고 깔끔한 교육용 클래식 블루 | 12px | 교과 수업, 학부모 총회, 교원 연수 |
| **네이버 그린** | 산뜻하고 가독성 높은 미니멀 에코 그린 | 6px | 동아리 발표, 친근한 안내 자료 |
| **현대카드 블랙** | 엣지 있는 다크 배경 & 옐로우 악센트 | 2px (Sharp) | 몰입감 있는 키노트, 특강, 포럼 |
| **정부·공문서** | 격식과 신뢰를 주는 단정한 네이비/그레이 | 4px | 학교 공식 행사, 교육청 보고, 연구회 |
| **카카오 옐로우** | 따뜻하고 경쾌한 버블 옐로우 & 소프트 블랙 | 22px (Round) | 학급 회의, 아이스브레이킹, 퀴즈 |

### 2. 🪄 양방향 AI 저작 엔진 (Google Gemini 연동)

#### ① ✨ 슬라이드 ➜ 맥락 맞춤 발표 대본 작성
슬라이드 요소들을 분석하여 자연스러운 발표 대본을 생성합니다.
- **맥락 인식 (Context-Aware)**: 각 장마다 "안녕하세요"가 반복되는 것을 방지하고, 직전 대본과 다음 슬라이드 내용을 파악하여 유기적으로 이어지는 연결 멘트를 구성합니다.
- **전체 슬라이드 일괄 배분**: 1번 슬라이드(도입/오프닝) ➔ 중간 슬라이드(본문 전개/전환) ➔ 마지막 슬라이드(결론/종합 요약)로 자동 안배합니다.
- **청중 맞춤 어투 선택**: 학생 대상(친근한 구어체), 동료 교사/연구회(전문적 교직 어조), 대강당(격식 공식 발표), 학급/동아리(활기찬 대화체)를 지원합니다.

#### ② 🪄 대본 ➜ 슬라이드 자동 기획 & 테마 정교화
강의 대본이나 설명 글을 슬라이드 비주얼로 자동 변환합니다.
- **🎨 기존 슬라이드 대본 기반 테마 정교화 (수정·튜닝)**:
  - 이미 작성된 슬라이드와 대본을 바탕으로, 현재 테마 규격에 맞춰 제목과 요약 카드를 세련되게 리디자인합니다.
  - **하위 분기**: '전체 슬라이드 일괄 정교화' 또는 '현재 슬라이드만 정교화' 지원
  - **[📚 전체 대본 모으기]** 기능으로 모든 슬라이드의 대본을 원클릭 통합 관리
- **🌐 통대본으로 전체 슬라이드 일괄 신규 제작**: 긴 강의 텍스트를 AI가 분석하여 도입·전개·결론 다중 슬라이드로 자동 분할 구성합니다.
- **➕ 개별 슬라이드 1장 신규 생성**: 특정 대본 단락에 맞추어 1장의 슬라이드를 추가합니다.
- **🛡️ 빈 슬라이드 방지 방화벽 (`ensureValidElements`)**: AI 응답이 불완전하거나 요소가 누락되어도 핵심 문장을 분석하여 테마 카드와 제목을 자동 합성하므로 빈 화면이 나오지 않습니다.

### 3. 📐 TeXZilla 내장 오프라인 수식 (LaTeX) 엔진
- 외부 인터넷 접속이나 외부 CDN 의존 없이 브라우저 자체에서 KaTeX/MathML급 수식을 100% 렌더링합니다.
- 교내망 차단이나 방화벽 환경에서도 안전하게 수식이 표시됩니다.
- **원클릭 수식 기호 팔레트**: 분수(`\frac`), 거듭제곱, 제곱근(`\sqrt`), 시그마(`\sum`), 적분(`\int`), 극한(`\lim`), 그리스 문자($\alpha, \beta, \theta, \pi$ 등)를 클릭 한 번으로 조합할 수 있습니다.

---

### 4. 🖥️ 독립 실행형 발표용 HTML 내보내기 & 듀얼 화면 연동
제작한 슬라이드를 **[🖥️ 발표용 HTML 저장]** 버튼으로 추출하면, 프로그램 설치 없이 더블클릭만으로 실행되는 고성능 프레젠터 파일이 생성됩니다.

- **발표자 화면 (노트북/태블릿)**:
  - 현재 슬라이드 미리보기 + 하단 발표 대본 상시 표시
  - 슬라이드별 대본 인라인 즉석 수정 및 자동 보존
  - 스톱워치/발표 타이머 내장
- **학생용 프로젝터 화면 (`?mode=screen`)**:
  - 대본과 조작 UI 없이 슬라이드 전체화면만 깔끔하게 투사
  - HTML5 `BroadcastChannel` 기반으로 발표자가 넘기는 슬라이드가 0.01초 딜레이 없이 실시간 동기화
- **오프라인 동작**: 인터넷이 연결되지 않은 교실에서도 완벽 작동합니다.

---

### 5. 🖨️ A4 1:1 완벽 분할 인쇄 (Print Scaler)
- **상하단 1:1 황금 분할**: A4 상단에 슬라이드(다크 테두리 액자 프레임), 하단에 발표 대본이 1:1 비율로 깔끔하게 배치됩니다.
- **고정 좌표계 벡터 배율기**: 슬라이드 원본 해상도(960px)를 고정한 후 CSS `transform: scale()`로 비례 축소하여, 인쇄 용지 폭에서도 폰트 크기 왜곡, 수식 깨짐, 카드 겹침 현상이 전혀 발생하지 않습니다.
- 스튜디오 에디터와 내보낸 발표용 HTML 파일 양쪽 모두 동일한 최고 품질의 인쇄를 보장합니다.

---

### 6. 🛠️ 강력한 저작 편의 도구
- **다양한 벡터 요소**: 제목, 본문, 벡터 도형 6종(직사각형, 둥근사각형, 원, 화살표, 말풍선, 배지), 로컬 이미지, 링크 버튼
- **도형 스타일 독립 제어**: 내부 채우기, 테두리 색상, 테두리 두께(0~8px), 도형 내부 텍스트 개별 커스텀
- **화면 비율 실시간 조절**: 16:9 와이드, 4:3 표준, 1:1 정방형, A4 가로
- **30단계 실행취소/다시실행**: `Ctrl + Z`, `Ctrl + Y` 단축키 지원
- **프로젝트 JSON 저장 & 로드**: 제작한 교안 데이터를 파일로 백업하고 동료 교사와 손쉽게 공유
- **[🔄 새로 만들기]**: 작업물을 안전 확인 후 1개 슬라이드 초기 상태로 깨끗하게 원클릭 리셋

## 💻 빠른 시작 (Getting Started)

### Vercel 배포 사이트에서 사용하기
1. 배포된 Vercel 웹사이트 URL로 접속합니다.
2. 1.5초간 인트로 화면이 표시된 후 스튜디오로 자동 진입합니다 (클릭 시 즉시 건너뛰기).
3. 상단 **[🔑 API 설정]** 버튼을 눌러 본인의 Google Gemini API 키를 등록합니다 (브라우저 로컬 저장소에만 보관되며 서버로 전송되지 않습니다).

### 로컬 환경에서 실행하기
본 프로젝트는 **빌드나 Node.js 설치가 전혀 필요 없는 순수 HTML5 앱**입니다.

```bash
# 1. 저장소 클론
git clone https://github.com/your-username/SlideTuningStudio.git

# 2. 폴더 이동
cd SlideTuningStudio

# 3. 브라우저에서 index.html 바로 열기 (더블클릭 또는 크롬 실행)
# Windows:
start index.html
# macOS:
open index.html
```

## 🔑 Google Gemini API 키 발급 안내
AI 대본 생성 및 AI 슬라이드 기획 기능을 사용하려면 Google Gemini API 키가 필요합니다 (기본 슬라이드 저작, 수식 렌더링, 인쇄, 발표는 API 키 없이도 100% 오프라인 사용 가능).

1. [Google AI Studio](https://aistudio.google.com/)에 접속하여 구글 계정으로 로그인합니다.
2. **"Get API key"** ➔ **"Create API key"**를 클릭하여 키를 생성합니다 (무료 티어 제공).
3. SlideTuningStudio 상단 헤더의 **[🔑 API 설정]**을 누르고 발급받은 키를 붙여넣은 뒤 저장합니다.
> 🔒 **보안 안내**: 입력하신 API 키는 브라우저 내부 `localStorage`에만 안전하게 보관되며, 어떠한 외부 서버나 제3자에게도 유출되지 않습니다.

## ⌨️ 단축키 안내 (Keybindings)

| 단축키 | 동작 |
| :--- | :--- |
| `Ctrl + Z` | 실행 취소 (Undo) |
| `Ctrl + Y` | 다시 실행 (Redo) |
| `Delete` / `Backspace` | 선택된 슬라이드 요소 삭제 (텍스트 입력 중 제외) |
| `←` / `→` (발표자/학생 모드) | 이전 / 다음 슬라이드 이동 |
| `Space` / `PageDown` (발표자 모드) | 다음 슬라이드 이동 |
| `PageUp` (발표자 모드) | 이전 슬라이드 이동 |
